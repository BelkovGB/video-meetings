# Plan: Транскрибация записей встречи локальным Whisper

**PRD**: [docs/prd-transcription-local-whisper.md](prd-transcription-local-whisper.md)
**Дата**: 2026-08-21

**Состояние** Фича сдана целиком: фаза 1 — PR #115, фаза 2 — PR #118. Открытые
замечания живут в беклоге GitHub отдельными issue.

## Фазы реализации

### Фаза 1: Очередь транскрибации и воркер

**Цель** Загруженная запись без участия пользователя превращается в файл
транскрипта с таймкодами и появляется в списке файлов встречи.

**Зависит от** ничего

**Затрагивает** database / backend

**Критерии PRD** 1, 4, 5, 7, 8, 9

**Задачи**

- [x] Добавить таблицу задачи транскрибации со статусами, арендой воркера,
      счётчиком попыток.
- [x] Создавать задачу при успешной загрузке файла категории `audio` либо
      `video`.
- [x] Захватывать задачу воркером атомарно, по одной за раз.
- [x] Приводить исходную запись к 16 кГц моно через ffmpeg перед
      распознаванием.
- [x] Сохранять результат файлом категории `transcript` мимо лимита активных
      загрузок, с учётом резерва свободного места.
- [x] Удалять транскрипт с задачей вместе с исходной записью.

**Когда готова** Загруженный mp3 появляется в списке файлов встречи как
транскрипт с таймкодами, загрузка pdf задачу не создаёт, две записи подряд
выполняются по очереди, удаление записи не оставляет файлов в хранилище.

### Фаза 2: Статус расшифровки на странице встречи

**Цель** Пользователь видит, что происходит с его записью: очередь, обработку,
готовность или ошибку с причиной.

**Зависит от** Фаза 1

**Затрагивает** backend / frontend

**Критерии PRD** 2, 3, 6, 7, 10

**Задачи**

- [x] Отдавать статус расшифровки записи в списке файлов встречи.
- [x] Отдавать машинный код причины ошибки в статусе, без путей хранения.
- [x] Показывать четыре статуса расшифровки в строке записи на странице
      встречи.
- [x] Обновлять статус на открытой странице, пока у встречи есть незавершённые
      задачи.
- [x] Показывать причину ошибки в строке упавшей записи.
- [x] Описать статусы расшифровки, коды ошибок, жизненный цикл воркера в
      документации API.
- [x] Описать конфигурацию воркера рядом с разделом
      `## Local upload configuration`.

**Когда готова** Открытая страница встречи показывает переход записи из очереди
в обработку и в готовность без перезагрузки браузером, упавшая запись показывает
причину ошибки, посторонний пользователь не получает ни статуса, ни транскрипта.
