# Plan: Автоматическая выжимка встречи

**PRD**: [docs/prd-auto-meeting-summary.md](prd-auto-meeting-summary.md)
**Дата**: 2026-08-23

## Фазы реализации

### Фаза 1: Выжимка появляется без кнопки

**Цель** Участник встречи с готовой расшифровкой видит выжимку, не нажимая
ничего.

**Зависит от** ничего

**Затрагивает** backend / frontend

**Критерии PRD** 1, 2, 8, 9, 10, 11, 12

**Задачи**

- [x] Вынести постановку выжимки в очередь в метод, доступный обоим путям
      запуска.
- [x] Добавить настройку интервала планировщика в
      `apps/api/src/meeting-summary/meeting-summary.config.ts`.
- [x] Запускать выжимку планировщиком для встречи с готовой расшифровкой без
      выжимки.
- [x] Пропускать встречу, у которой задание распознавания стоит в очереди или
      выполняется.
- [x] Показывать в панели встречи состояние «ждём расшифровку» до появления
      готовой расшифровки.
- [x] Продолжать опрос выжимки на открытой странице, пока выжимки ещё нет.
- [x] Переименовать кнопку запуска в «Обновить выжимку».
- [x] Описать автозапуск выжимки в `docs/api.md`.
- [x] Описать планировщик выжимки в `docs/api-architecture.md`.

**Когда готова** У встречи с готовой расшифровкой выжимка появляется на открытой
странице без нажатий, во время распознавания она не стартует, кнопка ручного
запуска остаётся на месте.

### Фаза 2: Новая расшифровка обновляет выжимку

**Цель** Участник добавляет расшифровку к встрече с готовой выжимкой и получает
пересчитанный результат.

**Зависит от** Фаза 1

**Затрагивает** database / backend

**Критерии PRD** 4, 5, 6, 12

**Задачи**

- [x] Добавить в таблицу выжимки поле отпечатка набора расшифровок вместе с
      миграцией.
- [x] Записывать отпечаток набора расшифровок при старте прогона.
- [x] Запускать пересчёт, когда отпечаток встречи разошёлся с записанным.
- [x] Оставлять упавшую выжимку без автоматического перезапуска до появления
      новой расшифровки.

**Когда готова** Новая расшифровка у встречи с завершённой выжимкой запускает
пересчёт, прежние задачи с договорённостями заменяются целиком, упавшая выжимка
сама не перезапускается.

### Фаза 3: Загрузка не сбивает выжимку

**Цель** Участник загружает файл в любой момент, а выжимка не стартует посреди
загрузки.

**Зависит от** Фаза 2

**Затрагивает** backend / frontend

**Критерии PRD** 3, 7, 11

**Задачи**

- [x] Считать активные загрузки по встрече в
      `apps/api/src/files/services/local-meeting-file-storage.service.ts`.
- [x] Пропускать в планировщике встречу, на которую сейчас идёт загрузка.
- [x] Оставлять форму загрузки доступной во время распознавания.
- [x] Оставлять форму загрузки доступной во время выжимки.
- [x] Описать условие «не стартуем во время загрузки» в `docs/api.md`.

**Когда готова** Файл загружается во время распознавания, загружается во время
выжимки, а пока идёт загрузка, выжимка не стартует.
